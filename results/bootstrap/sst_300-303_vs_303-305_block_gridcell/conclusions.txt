Caveat on independence
----------------------
  These CIs come from a BLOCK bootstrap by 'gridcell', which keeps
  correlated samples together and is more honest than i.i.d. when that
  axis carries autocorrelation. Note it controls correlation along ONE
  axis only; the other axis (and any block with few members) can still
  leave residual dependence. Compare against an 'iid' run to see how much
  the gridcell structure widens the intervals.
